# 거래 메뉴 원소스 기능 체크리스트

원소스 `/Users/hans/team/1-projects/ecoya-erp-v2/user-frontend`의 거래 화면, API route, 타입, 메시지, 테스트를 기준으로 프로토타입의 거래 메뉴를 구성한다. 원소스 UI를 복사하지 않고 기능과 상태 전이를 현재 shadcn 프로토타입의 화면 구조로 옮긴다.

> 아래 `[x]`는 **원소스에서 기능을 확인했다는 뜻**이며 로컬 프로토타입 구현 완료 표시는 아니다. 현재 구현 여부와 입력·표시 구분은 [`deal-detail-input-display-audit.md`](./deal-detail-input-display-audit.md)를 기준으로 판단한다.
