## 재대조에서 확인한 미이식/부분 이식

1. **비용 문서 확정 후 원가 제안**: 원본 `ConfirmStepTwoConnected`의 운임·보험·
   통관 문서 원가 제안은 현재 업로드 확정 흐름에 없다. 현재는 거래 상세에서 수동
   원가를 입력한다. 관세/VAT 분리 및 중복 비용 교체·건너뛰기도 미이식이다.
   근거: `costSuggestFromDocument.ts`, `ConfirmStepTwoConnected.tsx`.
2. **계약 단가 수정의 원천 필드 정정**: 원본 `07f17e29`, `2615a5b5`는 원천 문서
   사실과 감사를 연결한다. 현재 `FulfillmentTab`의 가격 수정은 로컬 `orderAction`
   및 이력만 반영하며 원천 송장/계약 가격과 목록 참고금액을 갱신하지 않는다.
3. **실제 서버 금융/OCR/확정 저장**: 화면과 금액 규칙은 반영했지만 ERP 인증,
   조직/거래 UUID, 서명 업로드, 서버 DTO 조회·갱신은 여전히 실제 Go API에
   연결되지 않았다. 모든 금융 화면이 운영 데이터를 공유한다고 판단하면 안 된다.

따라서 ‘원본 추가 기능이 전부 이식됐다’는 판정은 하지 않는다. 위 항목은 이번
UI 정리와 별개로 남은 기능 범위다. 현재 수정은 기존 UI와 모션을 보존하면서
확인 가능한 프로토타입 동작을 반영한 것이다.
