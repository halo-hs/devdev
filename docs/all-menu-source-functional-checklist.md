# 원소스 전체 메뉴 기능 체크리스트

## 목적

원소스 `/Users/hans/team/1-projects/ecoya-erp-v2/user-frontend`의 ERP 사이드바와 연결 화면을 현재 프로토타입에서 모두 접근 가능하게 만든다. Notion 페인포인트에 포함되지 않은 메뉴도 제외하지 않는다.

## 범위 판정

- **LNB 메뉴**: `src/features/erp/erpNav.tsx`에 직접 노출되는 장소
- **연결 화면**: LNB 메뉴의 행·CTA·탭에서 들어가는 상세 화면
- **운영 전용**: `/erp/ops/*`처럼 일반 ERP LNB가 아닌 별도 권한 영역
- 원소스 UI 문구는 임의로 재명명하지 않는다.
- 원소스 기능·상태·권한을 체크한 뒤 현재 프로토타입 UI로 재구성한다.
