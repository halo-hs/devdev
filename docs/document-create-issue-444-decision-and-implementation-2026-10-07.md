| 번호 | 결정 | 반영 상태 |
|---|---|---|
| 1 | 멤버 Seat 권한이 있는 사용자가 ‘승인 없이 진행’을 선택할 수 있으며, 실제 승인자는 관리자 레벨 이상 | 문구·권한 계약 확인 필요 |
| 2 | 항목마다 거래값·최근값·업로드값 후보를 선택 | 기존 후보 값 선택 UI 유지 |
| 3 | 은행 거절 전 점검은 거래처·통화·금액·품목 대조로 설명하고 AI 문구 제거. 불일치 수정 전 진행 차단 | 문구 수정 대상 |
| 4 | 문서 유형 변경 시 새 초안으로 다시 시작하고 기존 입력 초기화 안내를 한 번 표시 | 확인 안내 추가 대상 |
| 5 | 실제로 값을 미리 채울 수 있을 때만 거래값·업로드값 표시 | 카드 표시 규칙 정리 대상 |
| 6 | 문서함 근거 개수 제한 없음 | 선택 상한 제거 대상 |
| 7 | 품목 전체 삭제 후 저장 전 되돌리기 제공 | 기존 UI 반영 확인 |
| 8 | 같은 거래처 거래를 먼저 보여 주고 최신순 정렬 | 기존 정렬 로직 반영 확인 |
| 9 | 품목 단위는 회사별 관리 필요성 확인 후 결정 | 미결정: 회사 단위 설정 여부 |
| 10 | 기본 4색과 회사 브랜드 색을 제공하고 컬러 피커 추가 | 스타일 UI 추가 대상 |
| 11 | SVG 제외, PNG·JPG만 허용하고 최대 2MB | 업로드 계약 수정 대상 |

## 이번 작업에서 반영할 항목

- 문서함 근거 선택 개수 제한 제거
- 은행 거절 전 점검 설명에서 ‘AI가’ 문구 제거
- 문서 유형 변경 시 초기화 확인 안내
- 강조색 컬러 피커 추가
- 로고 업로드 허용 형식에서 SVG 제거

## 보류

- 품목 단위 회사별 설정 여부는 별도 결정 전까지 현재 단위 선택 UI를 유지합니다.
- 1번의 Seat·관리자 권한은 실제 권한 계약이 확정된 뒤 서버와 함께 연결합니다.
