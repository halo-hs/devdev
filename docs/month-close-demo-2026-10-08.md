# 월마감 예시 데이터와 확인 흐름

결산 리포트의 월마감 목록·상세·마감·재개방·재마감을 공개 예시 환경에서 확인하기 위한 데이터다. 실제 회계 기록이나 원본 서버 데이터를 변경하지 않는다.

## 데이터

[month-closes.json](../trade-os/operations/demo/month-closes.json)에 다음 내용을 모았다.

- `initialCloses`: 최초 월마감 목록. 2026-08은 재개방된 상태다.
- `snapshots`: 2026-08·2026-09의 통화별 집계, 고객사 Top, 일정 대사, 조정·부분 대손 상태. 기존 스냅샷 버전 7의 필드만 사용한다.
- `fallbackPeriod`: 다른 종료 월을 시연할 때 사용할 예시 금액 묶음. 선택한 월에 맞춰 기간·일정 날짜만 바꾼다. 실시간 계산 결과가 아니다.

마감 시 JSON에서 복사한 스냅샷을 브라우저 저장소에 저장한다. 상세 열기·재개방 시에는 저장된 값을 유지하고, 재마감할 때 새 스냅샷을 저장한다. 이전 예시 기록에 스냅샷 내용이 없으면 JSON으로 보완한다.

일반 브라우저에서는 새로고침 뒤에도 상태가 유지된다. 브라우저 저장소가 차단되면 현재 페이지 세션에서만 동작한다. 새 세션의 데이터는 초기 예시로 돌아간다.

## 확인 순서

1. `/erp/reports`의 2026-08 행을 열어 집계·고객사·일정 대사를 확인한다.
2. `재마감`하면 행이 `동결됨`으로 바뀐다.
3. 종료된 월의 `마감하기`를 눌러 저장하면 새 행이 추가된다. 메모는 선택이다.
4. 마감 행을 열어 금액·메모·스냅샷을 확인하고, 사유를 입력해 재개방한다.
5. 재개방 후에도 이전 스냅샷은 유지된다. 재마감하면 같은 행이 다시 동결된다.

진행 중인 달의 마감 금지, 중복 마감·중복 재개방 거부, 재개방 사유 필수 규칙은 유지했다. 사용자에게 보이는 상태·버튼 문구는 기존 계약을 사용한다. 모바일 스냅샷 창의 폭만 화면 안에 들어오도록 제한했다.

## 검증

- `npm run build`, 변경한 예시 API·테스트 ESLint 통과.
- 관련 브라우저 테스트 7개 통과: 운영 예시 읽기·선적 갱신, 기존 월 재마감, PC·모바일 신규 마감/재개방/스냅샷 유지, 과거 빈 스냅샷 보완, 저장소 차단 상태.
- 실제 서버의 권한·쓰기 성공 검증은 아니다.
