## 실제 서버 연결과 구분

현재 devdev ERP는 예시 데이터와 `prototypeBackend`를 사용하는 UI 프로토타입이다.
이번 작업은 최신 계약에 맞춘 **프로토타입 동작 이식**이며, 실제 서버 인증·OCR·
서명된 PUT 업로드·DB 저장을 연결한 배포가 아니다. 브라우저의 기록은 로컬 저장소에
남는다. 금융 DTO와 확정 경계가 같다는 것이 실제 백엔드 연동 완료를 뜻하지 않는다.

실제 연동에는 플랫폼 인증/조직 컨텍스트, 서버 문서·거래 UUID, 필드별 revision,
동일 출처 API 프록시가 필요하다. 파일명과 `DL-*` 예시 식별자를 서버 UUID처럼
전송하지 않는다. 이 작업에서는 원본 서버 및 Go 저장소를 변경하지 않았다.

  해당 거래 상세의 정산 탭을 직접 연다. CSV는 선택한 보기 기준이며 쉼표/따옴표를
  이스케이프하고 스프레드시트 수식 시작 문자를 보호한다.
- **거래 상세:** 기존 정산 탭 안에 거래 경제 요약, 원가 입력/수정/삭제,
  원가 계산 내역 표와 통화별 계산표를 배치했다. 정상 입력 시 상단에 미저장
  예상손익·마진을 미리 보여주고, 저장한 값과 구분한다. 취소하면 저장값으로

- **원가 규칙:** 원본의 정수 16자리/소수 2자리, 통화 USD/KRW/EUR/JPY/CNY,

  재차 차감하지 않으며 통화 간 금액을 합산하지 않는다. 기존 청구 일정 대조는
  유지했다. 원본의 실제 서버 재조회 대신 로컬 저장값으로 계산한다.

  공유한다. 출처/송장/일정 정보가 없는 다른 거래의 값을 추측하지 않는다.

- **선적 이하 메뉴:** 선적, 정산, 운영 감시, 결산 리포트, 영업 성과의 제목·필터·
