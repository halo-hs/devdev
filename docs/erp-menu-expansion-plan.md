## 2. 확정한 업무 의미

`정산`과 `결산 리포트`는 모두 회계처리를 위한 화면이다. 원소스가 명시한 것처럼 자체 회계 소프트웨어를 대체하는 것이 아니라, 무역 거래에서 확정된 값을 정리해 세무사·더존 등 후속 회계 처리로 넘기고 공식 보고 숫자를 마감하는 목적이다.

| 메뉴 | 사용자가 들어오는 이유 | 시간 기준 | 핵심 결과 |
| --- | --- | --- | --- |
| 오늘 할 일 | 지금 처리해야 할 업무 확인 | 오늘 | 우선순위 업무를 바로 실행 |
| 선적 | 선적 사실과 일정을 조회 | ETA/ETD | 지연·누락 여부 확인 및 거래 이동 |
| 정산 | 받을 돈(AR)·보낼 돈(AP)·자금 일정·환노출 확인 | 만기/기준일 | 입금·지급 기록, AR/AP 원장, 회계 인계 데이터 준비 |
| 운영 감시 | 예외와 위험을 조치 | 실시간 | 담당자 지정과 위험 해소 |
| 결산 리포트 | 월별 흐름과 기말 잔액 확인, 월마감 | 기간 단위/기간 | 회계 보고용 공식 숫자 동결과 마감 스냅샷 |
| 영업 성과 | 사람·거래처별 성과를 판단 | 선택 기간 | 성과 원인 확인과 후속 조치 |

화면과 메뉴의 용어는 원소스에 표시된 `정산`, `결산 리포트`, `월마감`을 그대로 사용한다. 두 화면은 합치지 않는다.

## 3. 사이드바 구조

기존에 별도 작업공간으로 확정한 `파일 올리기`와 `문서 만들기`는 유지한다.

1. 처음 시작하기
2. 오늘 할 일
3. 파일 올리기
4. 문서 만들기
5. AI에게 묻기
6. 기록
7. 거래
8. 선적
9. 정산
10. 운영 감시 - Owner/Admin만 표시
11. 경영·성과
12. 결산 리포트 - Pro
13. 영업 성과 - Pro
14. 설정 - 하단 고정

공통 상단 영역에는 원본과 동일하게 세계시간, 알림, 케밥 메뉴를 둔다. 메뉴는 장소를 나타내고, `파일 올리기`, `문서 만들기`, `고객 전달` 같은 실행은 각 작업공간의 CTA로 처리한다.

알림은 특정 업무 메뉴에 속하지 않는 공통 수신함이다. 알림 벨은 사이드바가 아니라 상단 우측 유틸리티 영역에 고정하고, 클릭하면 팝오버가 아닌 전용 `알림` 페이지로 이동한다. 전용 페이지에서 미확인·승인 요청·예외/위험을 필터링하고 읽음 처리한 뒤 관련 거래로 이동한다.

`처음 시작하기`는 원소스에서 일반 LNB가 아닌 온보딩 투어였지만, 현재 프로토타입에서는 사용자가 언제든 초기 설정과 진행 체크리스트를 다시 확인할 수 있는 접근 메뉴로 제공한다. 메뉴 안의 체크리스트 명칭은 원소스대로 `시작 가이드`를 사용한다.

## 4. 공통 화면 원칙

- [ ] 첫 화면 상단에는 `현재 판단 + 다음 액션`만 배치한다.
- [ ] 요약 카드는 판단에 필요한 최소 지표에만 사용한다.
- [ ] 비교 정보는 테이블, 근거와 수정은 패널을 사용한다.
- [ ] 동일한 상태나 설명을 상단·본문·패널에 반복하지 않는다.
- [ ] Primary CTA는 화면당 하나만 강조한다.
- [ ] AI 표시는 `결과, 신뢰도, 근거, 다음 액션`이 있을 때만 사용한다.
- [ ] 로딩, 빈 상태, 권한 없음, 일부 실패, 전체 실패를 구분한다.
- [ ] 오류 상태에 재시도, 마지막 정상 갱신 시각, 영향 범위를 표시한다.
- [ ] 역할과 요금제에 따라 메뉴·데이터·액션을 함께 제어한다.
- [ ] 화면 전환 시 탭·2단 상세 영역의 폭과 위치가 흔들리지 않게 고정한다.

## 5. 메뉴별 기능 체크리스트

이 문서는 UX 재구성 계획을 다룬다. 원소스의 전체 메뉴·연결 화면 기능 범위는 `docs/all-menu-source-functional-checklist.md`를 정본으로 사용한다. 페인포인트에 없는 메뉴도 구현 대상에서 제외하지 않는다.

### 5.1 오늘 할 일

**목표**: 대시보드를 구경하는 화면이 아니라 로그인 후 바로 일을 시작하는 화면.

원본 기능 보존:

- [ ] Member, Manager, Owner 역할별 데이터와 액션 범위
- [ ] 문서, 거래, 선적, 정산, 운영 감시의 미처리 업무 집계
- [ ] 파일 올리기, 문서 만들기, 거래, 정산으로 이동하는 빠른 실행
- [ ] 부분 API 실패 시 성공한 업무는 유지하고 실패 범위를 표시
- [ ] Owner/Manager용 경영 브리프와 재무·위험 요약

UI 개선:

- [ ] 첫 화면은 `오늘 처리 N건`과 우선순위 작업 목록으로 시작
- [ ] 각 행에 이유, 기한, 거래처/거래, 담당자, Primary CTA 표시
- [ ] 업무를 `지금 처리`, `오늘 안에`, `확인 필요`로 정렬
- [ ] Owner/Manager용 브리프는 오늘 업무 아래 보조 영역으로 이동
- [ ] 빈 상태는 단순 0이 아니라 완료 상태인지 데이터 실패인지 구분

### 5.2 선적

**목표**: 선적의 현재 사실을 빠르게 조회하고, 예외는 운영 감시로 넘긴다.

원본 기능 보존:

- [ ] 전체 선적 API와 SNAP 컨테이너 근거의 독립 로딩
- [ ] B/L, 컨테이너, 항구, 선박, 거래명, 거래처, SC/PO 검색
- [ ] 전체, 운송 중, 7일 이내 도착, 지연, 도착 필터
- [ ] 거래별 그룹 및 복수 B/L·분할 선적 표현
- [ ] ETA, D-day, 상태, 항로, 선박, 컨테이너 표시
- [ ] 거래 상세, B/L, SNAP 근거 이동
- [ ] 로딩, 재시도, 빈 상태

UI 개선:

- [ ] 상단 요약은 `임박`, `지연`, `B/L 누락`만 표시
- [ ] 본문은 사실 조회용 테이블로 유지
- [ ] 행 클릭은 선적 상세, 예외 CTA는 운영 감시로 이동
- [ ] `배송 추적`과 `선적` 용어를 `선적`으로 통일
- [ ] SNAP 실패는 선적 전체 오류로 보이지 않게 보조 근거 실패로 표시

### 5.3 정산

**목표**: 받을 돈(AR)·보낼 돈(AP)·자금 일정·환노출을 확인하고 입금·지급을 기록해 회계 인계 데이터를 준비한다.

원본 기능 보존:

- [ ] 정산 개요, 원장, 재무 사실, 근시일 현금 일정 조회
- [ ] 수금·지급 등록: 금액, 처리일, 은행 수수료
- [ ] 지급 기록 삭제 확인
- [ ] 완료 일정 되돌리기 확인 및 거래 상태 복원
- [ ] 연체 AR, 최우선 수금, 7일 수금·지급 판단
- [ ] 현금 전망, 자금 달력, 기간별 AR/AP
- [ ] 환 노출, 거래처 지급 신뢰도, 거래처별 AR/AP
- [ ] 수금·지급 원장, 거래/거래처 이동
- [ ] CSV, 세무 월별 명세서 내보내기
- [ ] 일부 새로고침 실패 시 마지막 정상 데이터 유지

UI 개선:

- [ ] 첫 구역을 원소스 명칭인 `오늘 결정`으로 유지
- [ ] 각 행에 받을 돈/줄 돈 방향, 마감일, 잔액, 위험, 처리 CTA 표시
- [ ] 상단에는 오늘 수금, 오늘 지급, 연체, 7일 현금만 표시
- [ ] `거래처별 AR/AP`, `AR/AP 원장`, `GP / 회계 인계 준비도`를 구분
- [ ] 환율·수익성·장기 에이징은 상세 분석 영역으로 이동
- [ ] `회계용 CSV 내려받기`, `세무사용 월간 명세서`가 입금·지급 액션보다 강해지지 않게 배치

### 5.4 운영 감시

**목표**: 예외를 보는 대시보드가 아니라 담당자를 정하고 조치하는 작업대.

원본 기능 보존:

- [ ] Owner/Admin 권한 제한
- [ ] blocked, risk, flag, pending action, throughput
- [ ] ETA 전 문서 누락, 잔량, 수량 불일치 패널
- [ ] 거래별 활성 위험을 심각도 순으로 집계
- [ ] 확인 처리 중 상태, 성공, 이미 처리됨, 실패 피드백
- [ ] 거래 상세 이동과 돌아올 경로 보존

UI 개선:

- [ ] 중복 카드와 패널을 하나의 우선순위 예외 큐로 통합
- [ ] 각 예외에 심각도, 영향 거래, 영향 금액/일정, 담당자, 다음 액션 표시
- [ ] `처리하기`, `거래 보기`, `담당자 지정`, `무시` 액션 제공
- [ ] 세부 패널은 선택한 예외의 근거로만 표시
- [ ] 오류 시 마지막 성공 시각과 누락된 데이터 범위 표시

### 5.5 결산 리포트

**목표**: 기간 단위와 기간을 선택해 월별 흐름과 기말 잔액을 확인하고, 확정된 달은 월마감해 회계 보고용 공식 숫자로 동결한다.

원본 기능 보존:

- [ ] Pro 권한 처리와 업그레이드 상태
- [ ] 월/주 조회 단위, 조회 기간, 통화 설정
- [ ] 정산 추이, GP 추이, 상위 미수·연체, 거래처 GP
- [ ] 계획 수금, 실제 수금, GP, 마감 잔액, 연체율 KPI
- [ ] 계획 대비 실적, GP, 잔액, 연체 차트
- [ ] 월마감 제안, Owner/Admin 마감 권한, 메모 입력
- [ ] 이미 마감됨, 권한 없음, 진행 중 월, 일반 실패 처리
- [ ] 동결 환율 근거를 포함한 월마감 스냅샷
- [ ] 로딩, 오류, 빈 상태

UI 개선:

- [ ] 원소스의 `기간 단위(월/주)`, `기간`, `통화` 컨트롤을 유지
- [ ] 월마감 첫 화면에 마감 가능 여부와 차단 요인 표시
- [ ] 미확정 거래, 미완료 정산, 누락 문서, 주요 변경을 체크리스트로 표시
- [ ] Primary CTA는 원소스 형식인 `{period} 마감하기`
- [ ] 마감 전 이슈 확인과 리포트 내보내기는 보조 액션
- [ ] 기간·통화 선택 후 KPI와 추이를 미리 검토
- [ ] 차트는 결론보다 아래에서 근거로 사용
- [ ] 마감된 달은 라이브 수치가 아니라 `마감 스냅샷`임을 명시

### 5.6 영업 성과

**목표**: 단순 순위가 아니라 성과 변화의 이유를 찾고 후속 조치한다.

원본 기능 보존:

- [ ] Pro 권한 처리
- [ ] Manager의 조직/담당자 필터와 Member의 본인 데이터 제한
- [ ] 매출·계획 수금, GP, 미수·연체, 활성 거래 KPI
- [ ] GP 추이와 Manager 전용 담당자 랭킹
- [ ] 거래처별 청구, 미수, 연체, 다음 마감, 선적, 문서, 최근 활동
- [ ] 로딩, 오류, 업그레이드, 빈 상태

UI 개선:

- [ ] Owner/Admin은 `팀 성과`, Member는 `내 성과`로 제목과 설명 변경
- [ ] `거래 파이프라인`과 분리해 사람·거래처 성과에 집중
- [ ] 변화 이유를 연체, GP 하락, 거래 정체, 문서 지연으로 표시
- [ ] 거래처·담당자 행에서 관련 거래와 후속 작업으로 이동
- [ ] 랭킹만 강조하지 않고 목표 대비·전기 대비를 함께 표시

## 7. 구현 순서

1. 공통 셸: 전체 사이드바, 역할/Pro 표시, 세계시간, 알림, 화면 라우팅
2. 처음 시작하기: 역할별 환영 화면, 초기 설정 마법사, 시작 가이드
3. 기존 화면 보완: 문서 올리기, 문서 만들기, 거래와 연결 상세
4. 선적: 조회 중심 화면과 거래·운영 감시 이동
5. 정산: 원소스의 정산·회계 인계 기능
6. 운영 감시: 우선순위 예외 큐와 조치 패널
7. 결산 리포트: 기간 조회, 월마감 준비도, 마감 스냅샷
8. 영업 성과: 역할별 성과와 원인·후속 작업
9. AI에게 묻기, 설정과 설정 하위 화면
10. 거래처 360, SNAP 증거함 등 연결 화면
11. 오늘 할 일: 앞선 메뉴의 작업을 모아 최종 작업 큐 구성
12. 전체 메뉴·기능·역할·상태 QA와 화면 캡처 갱신

`오늘 할 일`은 다른 메뉴의 상태와 딥링크를 모으는 화면이므로 마지막에 완성하되, 공통 셸 단계에서 기본 레이아웃과 작업 데이터 계약은 먼저 만든다.
