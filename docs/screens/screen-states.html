디자이너 요청

현재 구현된 기능·메뉴·데이터 의미와 디자인 시스템을 기준으로, 정보 배치와 사용 흐름을 정리해주세요. 아래 캡처는 **현재 구현 상태**이며 디자인 완료 시안이 아닙니다.

공통

• 일반 카드·입력창·버튼의 그림자를 줄이고 테두리와 여백으로 구분해주세요. 팝업·드롭다운·모달에 깊이를 남겨주세요.

• 큰 파란 배너를 제목·설명·주요 버튼 중심으로 줄이고 카드 안의 중첩 카드와 지표 장식을 정리해주세요.

• 제목 → 핵심 지표 → 주요 내용 → 상세 근거의 위계를 만들어주세요.

• 카드와 테이블 사이 여백은 10px입니다. 넘치는 내용은 테이블 내부에서 가로 스크롤되어야 합니다.

• 넓은 화면에서는 가용 폭을 사용하고, 좁은 화면에서는 필터·지표·버튼을 재배치해주세요.

홈

AI 질문 영역을 간결한 입력창으로 줄이고 ‘오늘 처리할 업무’를 가장 중요한 콘텐츠로 배치해주세요. 첫 화면에서 업무 목록이 보여야 합니다. 업무명, 거래처·거래, 기한, 상태, 구체적인 실행 버튼을 한 항목으로 구성해주세요. 업무 없음·최초 사용·조회 실패에서도 다음 행동을 제공해주세요.

AI에게 묻기

조회 범위·거래 선택 → 질문 → 답변·조회 결과 → 근거 → 원문·관련 업무 열기를 연결해주세요. 전체 조회인지 특정 거래 조회인지 입력창 옆에 표시하고, 요약·수치·표·근거의 위계를 구분해주세요. 통화·단위·기준 시점을 표시하고 대화 기록과 저장 답변의 역할을 나눠주세요. 분석 중·결과 없음·추가 질문 필요·근거 없음·오류에서도 질문과 범위를 유지해주세요.

선적·운영 감시

상태, 목록 선택, 상세 확인, 조치를 공통 패턴으로 설계해주세요. 선적은 실제 선적 목록을 먼저 두고 ‘선적 반영 대기 문서 검토’를 탭이나 접을 수 있는 영역으로 분리해주세요. 문서 내용 → 현재 선적 정보 → 차이 → 가능한 조치가 이어져야 합니다. 운영 감시는 서류 갭·미선적 잔량·수량 불일치 요약에서 문제 목록으로 연결해주세요. 진행 상태와 문제 상태를 구분하고 상세를 닫으면 필터·선택·스크롤 위치를 유지해주세요.

결산 리포트·영업 성과

제목·조회 조건 → 핵심 지표 → 주요 차트 → 상세표·집계 근거 순서로 통일해주세요. 결산의 큰 ‘청구서와 정산 일정 연결 현황’ 표는 차트 아래로 옮겨주세요. 조회 기간과 마감 대상 월을 구분하고 마감 상태와 액션을 함께 배치해주세요. 영업 성과는 핵심 지표 → 성과 추이·담당자 비교 → 거래처 상세표 순서로 구성하고 손실·원가 미입력·연체·실제 0·데이터 없음을 구분해주세요. 필터가 적용되는 지표와 상세표 범위를 명확하게 표시해주세요.

산출물 및 검토 기준

• 6개 페이지 데스크톱 1440px·모바일 390px 화면, 768px·1920px 배치 규칙.

• 네 업무 묶음별 대표 클릭 흐름과 해당 기능에 필요한 기본·선택·불일치·처리 중·완료·실패·데이터 없음 상태.

• 긴 거래처명·큰 금액·여러 통화·약 10건의 목록 예시.

• 공통 컴포넌트, 여백, 그림자, 상태 색상, hover·focus·disabled 기준.

• 검토 기준: 무엇을 먼저 확인하고, 다음에 무엇을 하며, 클릭하면 무엇이 열리는지 명확해야 합니다.
