# 입력 폼 공통 배치

문서 만들기·문서 올리기·거래 상세는 `src/components/form-field.tsx`를 사용한다.

- 상단 왼쪽: 라벨, 상태 뱃지.
- 상단 오른쪽: 오류·문서별 값 선택, 원본 보기 순서. 원본이 없으면 버튼과 자리 모두 생략한다.
- 중간: 입력 컨트롤. 수량/금액과 단위/통화는 같은 행에 배치한다.
- 하단: 아이콘과 안내·오류 문구. 긴 문구는 잘라내지 않고 줄바꿈한다.
- 좁은 화면에서는 오른쪽 액션 묶음을 다음 줄 오른쪽으로 넘긴다.
- 업무 필드 기본 높이는 40px. 인증 입력은 48px, 품목 표 내부의 조밀한 입력은 32px을 유지할 수 있다.
- 회원가입·인증과 설정 폼은 기존 배치를 유지한다. 비밀번호 보기·국가 선택·체크박스를 업무 폼 전용 액션과 섞지 않는다.

`FormField`는 상태와 부가 액션이 있는 필드, `SimpleFormField`는 하나의 입력을 감싸는 단순 필드에 사용한다. `FormFieldHeader`와 `FormFieldMessage`는 기존 표/레이아웃 안에서도 같은 규칙을 재사용한다.

오류 목록에서 이동할 때에는 헤더 버튼보다 입력 컨트롤에 먼저 포커스한다. 원본 보기는 실제 연결된 문서 패널을 연다. 문서 생성의 후보 값 선택은 명시적으로 버튼을 눌러 열고, 값을 선택하면 닫힌다.
