# 현재 구현 기준 · 공통 컴포넌트와 업무 UI

기존 ERP 611개 HTML 기준. 신규 인증 39개·별도 사이드바 캡처 8개는 이번 목록에서 제외합니다.

공통 컴포넌트(shadcn 기반 요소 + 기존 프로젝트 공통)는 재사용하고, 이를 조합한 업무 UI의 구성·상태·상호작용을 설계합니다. 사이드바는 기존 공통으로 재사용합니다. 테이블은 요청에 따라 별도 작업 항목으로 정리합니다.

[HTML 작업 안내](https://devdev-e6t.pages.dev/html/erp/designer-component-guide.html) · [Figma 작업 범위](https://www.figma.com/design/utViiVayT0rWuYSB5bpZ31?node-id=527-2)

## 재사용할 공통 컴포넌트

- **버튼·입력·선택**: Button, Input, Textarea, Select, Checkbox. 기존 공통 재사용. 크기·색·포커스·오류 상태 개선은 공통 기준으로 제안.
- **상태·탐색·레이어**: Badge, Tabs, Dialog, AlertDialog, Sheet, Popover, Tooltip, Skeleton, Progress. 기존 공통 재사용. 업무별 문구·위치·노출 조건·상태 연결을 설계.
- **표·차트 기반**: Table, ChartContainer, ChartTooltip + Recharts. 기반은 재사용. 테이블 타입과 그래프의 표현·필터·상세 연결은 별도 업무 UI 설계.
- **이미 정리된 공통 UI**: Sidebar · WorkspaceHeader · BusinessPageHero · SummaryMetricStrip · AutoSaveStatus · MoneyValue. Sidebar는 사용자 확인에 따른 기존 공통으로 분류. 신규 제작 대상에서 제외. 나머지는 적용 규칙·변형을 검토.

## 코드에서 공통 기반을 직접 쓰지 않은 사례

- **거래 만들기·거래 액션 모달**: deals-prototype.tsx DealCreateDialog / deal-detail-prototype.tsx ActionDialog: createPortal + div 직접 구성. 내용과 흐름은 업무 UI 설계. 팝업 기반 동작은 공통 Dialog 계열로 정리할 후보.
- **PDF·폼 비교/리사이즈 작업 영역**: App.tsx DocumentReviewWorkspace / PannablePdfViewport: 패널 조합·원문 이동·분할 제어. 버튼은 공통 재사용. 문서와 폼 연결·스크롤·좁은 화면은 전용 업무 UI 설계.
- **선적 일정·순위/사용량 막대**: 거래 FulfillmentTab 날짜축·구간 직접 배치 / 영업 성과·토큰 div width 막대. 일정·순위·사용 비율의 의미별 UI를 정리. 기본 막대를 단순히 같은 차트 타입으로 통일하지 않음.

## 611개 근거 목록

전체 화면별 사용 마커와 기타 태그 확인 후보는 `ui-component-inventory-562.json` 및 HTML 안내 하단에서 확인합니다. Sidebar는 기존 프로젝트 공통으로 별도 분류합니다. native 태그 검출만으로 shadcn 미사용을 단정하지 않습니다. 기본·상세·팝업·상태 파일을 합한 수이며 611개 독립 페이지 또는 새 컴포넌트가 아닙니다.

## 디자이너에게 전달할 요청

- 공통 요소의 모양·상태 변경이 필요하면 공통 변경안으로 제안합니다. 페이지마다 별도 복제본을 만들지 않습니다.
- 테이블은 별도 산출물로 받습니다. 조회형·편집형·문서 비교형을 구분하고, 공통 Table·Input·Select·Button을 기반으로 행과 셀의 업무 규칙을 설계합니다.
- 폼은 공통 Input·Select를 사용합니다. 추가 설계 대상은 검증 안내·배치·읽기/편집·업무 상태의 조합입니다.
- 각 업무 UI는 적용 페이지, 재사용할 공통 요소, 기본·빈 상태·오류·처리 중·완료·좁은 화면, 버튼 이후 흐름을 함께 보여주세요.
- 표·카드·버튼의 그림자는 공통 계층 규칙으로 조정합니다. 기존 배치나 그림자 값을 그대로 따르라는 의미가 아닙니다.
- 611개는 상태·팝업을 포함한 참고 파일 수입니다. 611개를 각각 새 컴포넌트로 만들지 않습니다.
