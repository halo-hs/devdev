# 메뉴 목록 검색·필터 공통 기준

2026-09-21 로컬 소스 적용. 검색 조건·권한·조회 방식은 각 메뉴에서 관리하고 표현을 공통으로 사용합니다.

- `BusinessListToolbar`: 검색·실행 버튼 → 필터 → 결과 수/조회 기준 순서. 검색이 없는 메뉴는 필터·실행 버튼부터 표시.
- `BusinessFilterSearch`: 검색 아이콘 왼쪽, 지우기 오른쪽. 지우면 검색창으로 포커스를 돌리고 기존 상태 필터는 유지.
- `BusinessFilterField` / `BusinessFilterSelect`: 선택값과 별개로 필터 라벨을 계속 표시. 통화·담당자 등 단일 조건은 드롭다운, 상태·짧은 기간 전환은 탭/세그먼트.
- 컨트롤 외곽 높이 `--control-size-md`(40px), 글자 `--text-body-9`(14px), 컨트롤 간격 8px, 행 간격 12px. 탭/세그먼트 내부 버튼은 외곽 패딩·테두리를 제외한 높이를 사용.
- 검색·필터는 왼쪽, 새로고침·내려받기 등은 오른쪽. 좁은 화면에서는 DOM 순서대로 줄바꿈.
- 배너 안에서는 기존 반투명 토큰, 흰 목록에서는 일반 컨트롤 토큰. 색을 위한 화면별 복제 컴포넌트를 만들지 않음.

| 적용 메뉴 | 내용 |
|---|---|
| 문서 올리기 | 상태·유형·정렬의 지속 라벨, 왼쪽 필터, 필터링된 결과 수. 업로드 내부 대기 목록에도 같은 구성 적용. |
| 문서 만들기 | 검색 왼쪽, 상태 탭 다음 줄, 검색과 현재 탭을 함께 적용한 결과 수. |
| 거래 | 공통 검색·드롭다운, 상세 필터 버튼 오른쪽, 선택 조건 및 기존 필터 동작 유지. |
| 선적 | 공통 검색, 기존 상태 탭, 필터링된 거래·선적 건수. 거래별 그룹 및 갱신 동작 유지. |
| 정산 | 통화·취소 포함 왼쪽, 새로고침·대상 월·다운로드 오른쪽, 기준 시각 아래. 대상 월은 내보내기 범위이므로 다운로드 옆에 유지. |
| 운영 감시 | 기간·수량 라벨과 전환, 새로고침 오른쪽. |
| 결산 리포트 | 기간 단위·기간·통화·담당자 라벨, 통화 드롭다운, 조회·마감 오른쪽. |
| 영업 성과 | 기간·통화·담당자 라벨, 통화 드롭다운, 조회 범위 아래. |
| 알림 | 흩어진 왼쪽 분류와 오른쪽 검색을 배너의 공통 검색·분류 영역으로 통합. 전체/선택 읽음 처리는 유지. |

설정 탐색 검색, AI 대화 검색, 문서 연결 팝업의 검색은 메뉴 목록과 역할이 달라 이번 적용 대상에 포함하지 않습니다. 사용되지 않는 과거 프로토타입도 활성 메뉴 수에 포함하지 않습니다.

검증: 1440px/390px에서 9개 메뉴의 필터 넘침·라벨·크기, 문서 상태와 검색 조합, 검색어 지우기와 포커스, 업로드 필터, 알림 분류, 리포트·영업 통화 변경. 예시 데이터 상태 회귀 테스트 및 TypeScript/프로덕션 빌드 확인.
