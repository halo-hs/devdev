# 로그인·회원가입 오류 표시 점검

## 확인 결과와 보완

기존 로그인에는 인증 실패·소셜 공급자 오류·세션 만료·조직 없음 안내가, 가입에는 비밀번호 불일치·조직 생성 부분 실패·승인 대기/거절 안내가 있었다. 필수값과 이메일 형식은 브라우저 툴팁 및 비활성 버튼에 의존했고 오류와 입력란의 접근성 연결이 없었다.

- 로그인과 가입 폼에 `noValidate`를 적용해 브라우저 기본 검증 툴팁을 사용하지 않는다.
- 입력란을 벗어나거나 제출했을 때 필수값·이메일 형식·비밀번호 길이·비밀번호 확인 오류를 해당 입력란 바로 아래에 표시한다.
- 오류는 기존 디자인 시스템의 `aria-invalid` 빨간 테두리와 오류 문구를 함께 사용한다.
- 오류 문구는 `aria-describedby`로 연결하고 `role=alert`로 알린다. 제출하면 첫 오류 입력란으로 포커스를 이동한다.
- 잘못된 값을 수정하면 메시지를 제거한다. 다른 유효 입력은 보존한다.
- 필수 동의가 없으면 계정 만들기를 비활성화하고 이유를 설명한다.
- 로그인 연결 실패·계정/조직 조회 실패·시도 제한, 가입 계정 생성 실패·연결 실패·약관 조회 실패의 화면 미리보기를 추가했다.
- 조회 실패를 조직 없음/가입 완료로 취급하지 않는다. 중복 가입 대신 로그인·기존 정보 확인 경로를 안내한다.
- 로그인·가입 주요 본문/입력/버튼은 16px, 입력 높이는 48px로 조정했다. 무료체험 CTA는 흰색 버튼, 제품 아이콘은 40px다.

## 동작 범위

현재 인증은 로컬 프로토타입이다. 계정 조회·생성, 소셜 OAuth, 실제 가입 중복 판정, 서버 시도 제한, `/me` 재조회, 네트워크/페이지 오류 매핑은 운영 API에 연결되어 있지 않다. 신규 서버 오류 상태는 개발 모드의 `/login?preview=1`, `/signup?preview=1` 선택기로 검토한다. 오류 화면의 돌아가기 버튼은 로컬 화면 복귀이며 실제 서버 재시도 성공을 뜻하지 않는다.

가입 단계 자체의 Account/Organization 분리는 별도 SSOT 화면 확정 및 연동 작업이며 이번 오류 표시 보완으로 완료됐다고 보지 않는다.

## 검증

`tests/auth-errors.spec.ts`: 1440px/390px 입력 오류, 첫 오류 포커스, 설명 연결, 수정 후 오류 해제, 동의/입력 유지, 페이지 오류와 제품 접근 차단. 매직링크 테스트와 함께 14개 통과.
