# 문서 올리기 플로우 결정 기록

기준일: 2026-08-28

## 결정 내용

문서 올리기 상세은 `필드 검토 → 거래 연결`의 2단계로 구성하며, `문서 확인`과 `문서 확정`을 별도 처리 상태로 추가하지 않는다.

## 배경

프로토타입을 정리하는 과정에서 문서 만들기의 검토·확정·공유 흐름이 문서 올리기에 섞여, 필드 검토 뒤에 거래 후보가 아닌 문서 확인·확정 UI가 노출되었다. 실제 플랫폼의 업로드 확인 흐름과 역할 경계를 다시 맞출 필요가 있다.

## 실제 플랫폼 근거

- `ConfirmStepOneView`: 필드 검토 단계
- `ConfirmStepTwoView`: 거래 연결 단계이며 거래 후보를 라디오 목록으로 선택
- 거래 후보 확인 시 `assignAndCommitLinkedDeal`이 `assign → commit`을 연속 수행
- 완료 후 다음 검토 문서 또는 문서함으로 이동
- `문서 확인`은 확인 화면의 페이지명으로 사용되지만, 업로드 처리의 독립 상태는 아님
- Magic Link·이메일 공유·문서 모양·승인·문서 확정은 문서 만들기 흐름에 속하며 문서 올리기에 넣지 않음

## 검토한 옵션

1. `필드 검토 → 문서 확인 → 거래 연결 → 문서 확정`으로 세분화
2. `필드 검토 → 거래 연결`로 실제 플랫폼과 동일하게 유지

## 선택한 이유

- 거래 연결 확인 동작이 문서 배정과 commit을 함께 수행하므로 별도의 확정 화면이 필요하지 않다.
- 사용자가 필드 검토를 마친 다음 해야 할 일은 거래 후보 선택이다.
- 문서 만들기의 확정·공유 개념과 업로드 문서의 검토·배정 개념이 섞이지 않는다.

## 화면 및 문구 규칙

- 1단계 상단 액션: 실제 플랫폼과 동일한 `다음`
- `다음` 클릭 결과: 오른쪽 오버레이 패널에 거래 후보 목록 노출
- 2단계 제목: `거래 연결`
- 1단계는 `왼쪽 항목 검토 / 오른쪽 PDF`, 2단계는 `왼쪽 PDF / 오른쪽 거래 연결`의 전체 2분할 화면으로 표시
- 2단계 오른쪽 패널은 연결 요약, 거래 후보, 직접 검색·새 거래 등록 순으로 제공하고 하단 고정 액션바에서 항목 검토로 돌아가거나 연결을 확정
- 패널을 닫으면 파일 검토 화면의 기존 위치로 복귀
- 거래 연결 패널에는 PDF 다운로드를 넣지 않고 거래 선택·새 거래 등록·최종 연결만 제공
- 후보 선택만으로 반영하지 않고 `선택한 거래 연결`을 눌러 완료
- 거래 연결과 문서 commit이 성공하면 연결된 거래 상세로 바로 이동
- 은행거래내역서는 목록에서 `거래 연결 필요` 상태로 진입할 수 있으며, 기존 거래 선택 후 동일 통화의 미결제 일정·금액·입금일을 확인해야 연결 가능
- 거래 연결 상단에서 `거래 후보에서 선택 | 새 거래 등록` 두 경로를 2분할 선택 영역으로 제공
- 새 거래 등록을 선택하면 거래처명을 확인하고, 새 거래 생성과 문서 연결을 한 번에 완료
- 후보 조회 실패 시에는 중복 생성 위험 때문에 새 거래 등록을 노출하지 않고 `다시 불러오기`만 제공
- 후보가 있으면 `거래 후보에서 선택`을 기본으로 표시
- 후보가 없거나 사용자가 `새 거래 등록`을 선택하면 등록 폼으로 전환
- 거래 연결 완료 후 별도 `문서 확인` 또는 `문서 확정` 화면을 노출하지 않음
- 완료 문서는 검토·배정 대기 목록에서 제외

## 포기한 것

- 업로드 문서에서 확정 전후를 별도 화면으로 세밀하게 보여주는 방식
- 문서 올리기 상세에서 공유까지 연속 처리하는 방식

## 재검토 조건

- 백엔드가 거래 배정과 문서 commit을 분리된 API·권한·상태로 제공할 때
- 업로드 문서도 생성 문서와 동일한 승인·공유 프로세스를 가져야 한다는 제품 결정이 확정될 때

## 문서 만들기와의 용어 경계

- `AI로 초안 만들기`: 자연어를 구조화된 필드 제안으로 바꾸는 액션
- `문서 초안 만들기`: PDF 초안이 아직 한 번도 생성되지 않았을 때만 사용
- `PDF 보기`: 초안이 한 번이라도 생성된 뒤 PDF 화면으로 이동하는 고정 액션. 수정값이 있으면 이동하면서 반영함
- `문서 확정`: 검토·거래 연결·필수 점검·승인 조건이 끝난 생성 문서를 잠그는 액션이며 문서 올리기에는 사용하지 않음
