# 거래 상세 구현 커버리지 매트릭스

원소스 상세 체크리스트 79개 항목을 현재 로컬 프로토타입과 대조했다. `완료`는 화면과 상호작용이 목적에 맞게 존재하는 경우, `부분`은 외형이나 버튼만 있고 입력·권한·실패 처리가 덜 된 경우, `누락`은 해당 상태나 기능이 없는 경우다.
