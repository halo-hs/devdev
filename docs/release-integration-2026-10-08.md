- 통합본 `npm run build` 통과. 기존 Lottie eval·큰 chunk 경고는 남아 있다.
- Chrome의 관련 테스트 62개 통과: 거래 상세·원가 계산, 문서 만들기·올리기·PDF, 공유 첨부·링크 철회, 운영 화면·월마감 예시, 정산 조건부 문구, 단일 스크롤, 공개 페이지·인증 헤더의 언어 선택.
- 1440/390px를 포함하고 PDF 좌우 패널은 1024/1200/1440px를 확인했다. 언어 선택은 `/`, `/trade-os`, `/snap`, `/pricing`, `/contact`, `/login`, `/signup`, `/terms`에서 확인했다.
- 운영 화면은 예시 모드로 검사했다. 실제 서버 쓰기·권한·발송·CSV 성공 및 원본 서버와의 live parity를 확인했다는 의미가 아니다. 남은 기능 차이는 [후속 액션 기록](./operations-follow-up-action-gap-audit-2026-10-08.md)에 유지한다.

## 병합 규칙

`main`은 PR과 다른 사람의 승인 1개가 필요하며 관리자에게도 적용된다. 직접 push, 보호 규칙 우회, 로컬 직접 Production 배포를 하지 않는다. 이 통합 PR 승인·검사 완료 후 main으로 병합하고, Git 연동 Production이 병합 커밋을 사용했는지 별도로 확인한다. PR 작성 또는 Preview 성공 자체는 운영 배포 완료가 아니다.
