# ERP 인계 UI 반영 — 2026-09-14

기존 거래 목록·상세의 5개 탭과 서류 작업대를 유지하고, 인계 문서 `4. FRONTEND-ADDED-UI-DESIGN.md`의 거래 범위 안에 진입 버튼을 추가했다.

- 상세: 문서 간 단건 품목 관계 연결·해제·이력. 수량 초과와 중복을 검사하며, 관계 해제는 문서의 거래 연결을 제거하지 않는다.
- 상세: 서류 필요 일시·준비 상태·기존 선적 참조·확보 근거·메모. 확보 상태는 해당 종류의 문서 근거가 있어야 저장할 수 있다. 요청 기록은 메시지 발송이 아니다.
- 주문·선적: 계약 품목별 계약량과 포장명세 근거량·잔여량 조회. 계약 배정 API가 연결되지 않아 배정/취소/재개 쓰기 작업은 추가하지 않았다.
- 정산: 청구 원천과 기존 정산 일정 후보의 거래·금액·방향 대조 및 기존 정산 페이지 이동. 후보를 실제 연결로 표시하거나 일정을 생성하지 않는다.
- 관계자: 문서상 당사자와 등록 거래처 후보의 연결·변경·해제, 사유·수행자·시각 이력. 일반 이름 편집은 유지한다.
- 정산 이동 후 브라우저 뒤로가기로 거래의 선택 탭을 복원한다. 별도 탭·사이드바 메뉴·금융 업무 완료·후속 업무함은 추가하지 않았다.

추가 기록은 로컬 UI 샘플이며 해당 거래 화면이 마운트된 동안 유지된다. Go API·DB 저장 또는 실제 메시지 발송을 구현/검증한 것으로 간주하지 않는다. 거래처 후보 역시 로컬 예시 목록이다.

함께 반영한 기존 요청: AI `/erp/ai` 진입·호환 링크 및 업무 조회, 선적/정산/운영감시/리포트/영업성과의 사례별 샘플, 조직명·제품별 요금제, 팝업 레이어, ERP 가용 폭, 영업성과 테이블 내부 가로 스크롤과 카드 10px 안쪽 여백.

검증: TypeScript 및 production 빌드, 변경 코드 ESLint, Chrome/Firefox/WebKit의 AI·샘플·폭·팝업·거래 기능 브라우저 테스트. unrelated 로컬 설정·문서 검토·토큰 변경과 스크린샷은 이 커밋에 포함하지 않는다.
