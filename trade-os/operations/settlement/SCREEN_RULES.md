# 정산 화면 — 지급 독촉 표시 규칙

사용자 확정: 2026-10-16. 적용 경로: `/erp/settlement`. 이 규칙은 devdev 프로토타입 화면의 표시 계약이다.

- 기본은 가장 급한 독촉 대상 **1건**만 제목과 같은 가로 줄에 표시한다. 좁은 화면에서는 줄바꿈한다.
- 대상 선정과 정렬은 기존 `selectSettlementDunningEntries`를 유지한다. 미결제 받을 돈 중 종료되지 않은 건, 연체 우선, 지급기한 오름차순(기한 없음은 뒤), 기존 동률 정렬을 따른다.
- 대표 줄에는 거래처·연체 여부·미결제금액·지급기한·미리보기·복사 아이콘을 표시한다. 금액과 기한에 라벨을 붙인다.
- `전체 N건`은 필터가 적용된 독촉 대상 전체 건수이며 연체 건수나 고유 거래처 수가 아니다.
- 전체 버튼을 누르면 같은 영역 아래에 모든 대상이 펼쳐진다. 제목 줄의 대표 1건은 사라지고 목록의 첫 행으로 들어간다. 중복 표시하지 않는다.
- 펼친 목록의 헤더는 거래처 / 미결제금액 / 지급기한 / 작업이다. 모바일은 각 값의 라벨로 대체한다.
- 다시 누르면 가장 급한 1건만 표시한다. 우측 패널은 사용하지 않는다.
- 각 행은 작은 흰색 사각형 `미리보기 | 복사 아이콘` 버튼을 사용한다.
- 미리보기는 클릭형 팝오버이며 독촉 전문과 `복사하기`, `메일 앱 열기`를 표시한다. 공통 문구 편집과 행 안 초안 펼침은 없다.
- 복사는 해당 건의 치환된 초안을 클립보드에 기록하고, 메일은 같은 초안의 mailto를 연다. 자동 발송하지 않는다.
- 로딩·조회 실패/재시도·대상 없음 표시는 기존 동작을 유지한다.

- 미리보기·복사 아이콘은 간격 없이 하나의 사각형 버튼 묶음으로 표시한다. 복사 성공·실패는 토스트로만 알리고 미리보기 안에 상태 문구를 추가하지 않는다.
