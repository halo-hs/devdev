# 연락처·파이프라인 화면 상태

이 저장소는 프로토타입입니다. 연락처와 활동은 예시 데이터, 추가·수정은 현재 화면의 로컬 상태입니다. 서버 API·실제 인증 권한을 구현하거나 검증한 것으로 해석하지 않습니다.

## 화면 확인

`/erp/sales?salesState=값`으로 진입합니다. 거래 목록의 `연락처·파이프라인` 버튼은 이 화면으로 이동만 합니다(SSOT SC-14·#443 P3). 상태 지정이 없으면 정상 예시 화면입니다. URL은 시안 검증용이며 권한 판정 수단이 아닙니다.

| 값 | 표시 및 동작 |
| --- | --- |
| list-loading | 목록 스켈레톤. 빈 결과·상세를 표시하지 않음 |
| list-error | 목록 조회 실패 + 다시 시도. 기존 상세 숨김 |
| list-empty | 연락처 없음 안내. 추가 후 새 연락처 선택 |
| detail-loading | 선택 연락처 상세 스켈레톤 |
| detail-error | 일시 상세 실패 + 다시 시도. 선택 유지 |
| forbidden | 권한 안내, 상세·수정·재시도 숨김 |
| not-found | 삭제 또는 접근 불가 안내, 재시도 숨김. 다른 연락처 선택 가능 |
| archived | 보관 배지·안내, 기존 이력 조회 허용, 수정 숨김 |
| readonly | 조회 허용, 추가·수정 숨김 및 저장 핸들러 차단 |

재시도는 로딩을 거쳐 동일한 로컬 예시 데이터를 표시합니다. 검색 결과가 없으면 이전 상세를 숨기며, 검색 결과가 있으면 첫 결과를 선택합니다. 연결된 거래가 있지만 활동이 없는 연락처도 활동 없음 안내를 표시합니다.

## 서버 연결 시 교체할 부분

- 목록/상세 로딩과 실패 상태를 실제 요청 결과에 연결하고 취소·지연 응답을 처리합니다.
- forbidden은 403, not-found는 404/410 등 실제 응답에 연결합니다.
- canWrite는 서버 제공 capability, 보관은 archived_at으로 판정하고 서버 쓰기 권한도 검증합니다.
- 추가·수정 성공, 충돌 및 저장 실패를 실제 응답과 연결합니다.
- 목록 쪽 이동은 서버 has_more/cursor 계약을 사용합니다. 현재 로컬 배열 길이를 서버 전체 건수로 사용하지 않습니다.
- 활동·거래·금액·시간대는 서버 근거를 사용하며 통화를 합산하지 않습니다.
