QA 기준

이 절은 앞선 제품 계약을 검증하기 위한 점검 항목이며, 독립적인 제품 요구사항을 추가하지 않는다.

  • Firebase 계정 성공과 워크스페이스 생성 성공을 하나의 저장 단계로 판단하지 않는다.
  • 필수값·비밀번호 불일치·동의 누락·중복 계정·워크스페이스 실패를 구분한다.
  • FE 표시 artifact와 서버 선택 artifact가 다르면 동의를 저장하지 않는다. 미확인 법무 값을 임의 version·효력일로 대체하지 않는다.
