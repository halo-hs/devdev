CS-07 — ECOYA Platform Common Organization 컨텍스트

결정 반영: 2026-08-19 Organization·Paddle Customer·제품 관계 — COMMON:DEC-WORKSPACE-001, COMMON:DEC-PRODUCT-REL-001

추가 반영: 2026-08-26 무료체험 정책 — COMMON:DEC-TRIAL-001

모델

Account
├─ Organization A Membership — OWNER
├─ Organization B Membership — ADMIN
└─ Organization C Membership — MEMBER

OrganizationContext = 현재 선택한 활성 Membership 하나

Account와 Organization은 N:M이다. 같은 Account도 Organization마다 역할과 제품·메뉴 접근이 다르다.

선택·전환

Membership 결과 화면
0건·정상 신규/의도적 이탈/제거 Organization 만들기·초대 참여
0건·projection 이상 Organization 접근 복구
1건 서버가 해당 Organization을 검증한 뒤 다음 landing 판정
복수·유효한 현재값 있음 현재 Organization으로 다음 판정
복수·현재값 없음/무효 Organization 선택
선택 조직 lifecycle 제한 접근 제한·다른 Organization 전환

Membership 0건의 원인은 서버가 판정한다. FE가 과거 URL·로컬 캐시·최근 Organization만 보고 복구 여부를 추론하지 않는다.

Organization 전환 시 폐기

  • 이전 Organization role·Membership capability
  • Product Subscription·trial·entitlement
  • 제품·메뉴 접근 권한
  • 제품 데이터·사용량·query cache
  • Paddle portal/invoice grant
  • 이전 Organization을 포함한 안전하지 않은 next

선택 뒤 /me와 entitlement를 fresh fetch하고 server landing을 처음부터 다시 실행한다.

Organization 생성

  • 신규 직접 가입의 첫 Organization 생성자는 OWNER다.
  • 기존 Account도 새 Organization을 명시적으로 생성할 수 있고 생성자가 OWNER다.
  • 개수·플랜·운영 승인 제한은 없다.
  • 초대 수락은 기존 Organization에 가입하며 새 Organization을 만들지 않는다.
  • Organization 생성은 제품 구매나 trial 시작을 자동 실행하지 않는다.

제품·데이터 경계

  • Product는 Organization 아래 entitlement로 연결되며 별도 Workspace를 갖지 않는다.
  • 제품 데이터는 organization_id + product로 범위화한다.
  • Organization Member의 제품·메뉴 권한과 객체 공유 범위를 추가 확인한다.
  • 같은 Organization과 Bundle을 이유로 제품·Deal 데이터를 자동 공유하지 않는다.
  • 제품 간 이동은 명시적 handoff만 허용한다.

자기 이탈

CF-05를 따른다. 마지막 OWNER는 다른 활성 OWNER가 생기기 전까지 이탈할 수 없다. 성공 뒤 Account와 다른 Organization Membership은 유지한다.

legacy 호환

legacy 최종 해석
workspace_id Organization 식별자 호환값
next_workspace_id 다음 OrganizationContext 식별자 호환값
TenantContext OrganizationContext
Trade OS Space/ERP Workspace Organization + TRADE_OS migration source
SNAP Organization 최종 Organization migration source
needs_workspace organization_required 또는 서버가 판정한 복구 상태

legacy 값을 제품 Workspace 존재·제품 Membership 승인 근거로 사용하지 않는다.

IMPLEMENTATION_GAP

  • `COMMON:DEC-MIGRATION-001`의 단일 Organization registry·legacy ID mapping·cutover
  • OrganizationContext 선택·전환 API와 cache invalidation
  • Membership 0건 reason classifier와 복구 상태
  • Product Entitlement·제품/메뉴 접근 projection

QA

  • 0/1/복수 Membership과 무효 현재값을 확인한다.
  • 정상 Organization 없음과 projection 이상 복구를 구분한다.
  • 전환 뒤 이전 역할·메뉴·제품·Paddle grant·데이터가 재노출되지 않는다.
  • 유료 구독 0개·trial 활성·무료 이용량 소진·기간 종료·유료 활성 Organization을 각각 확인한다.
  • legacy ID를 사용한 직접 URL에서도 서버가 최종 Organization과 제품 접근을 재검증한다.
