MEMBER는 조직 안내 구획을 표시하지 않고 진행 X/4를 사용한다. 내부 상태 enum을 사용자에게 표시하지 않으며 완료, 진행 중, 다음, 권한 필요를 항목명·icon·한국어 보조 문구로 전달한다.

항목 상태와 행동

표시 의미 CTA
완료 검증된 완료 사건 존재 기본 CTA 없음
다음 현재 바로 실행 가능한 첫 미완료 항목 해당 화면으로 시작
진행 중 처리 또는 외부 결과를 기다림 상태 보기
이어하기 기준 객체가 있고 다음 사용자 행동 가능 같은 객체의 목적 화면
권한 필요 현재 capability로 행동 불가 잠금 이유만 표시; 임의 요청 action 없음
일시 오류 progress 또는 target 조회 실패 다시 시도

사용자가 항목을 직접 체크하거나 완료로 PATCH하지 않는다. 실제 제품 성공 사건 또는 Common education receipt가 projection을 갱신한다.

클릭 뒤 안내

  • 항목 CTA 클릭만 1회성 guide intent를 만든다.
  • 목적 화면이 준비되면 해당 interactive control에 keyboard focus를 옮기고 target 주변을 강조한다.
  • popover는 현재 해야 할 한 행동, 완료 기준, 닫기만 제공한다. 여러 화면 tour를 한꺼번에 실행하지 않는다.
  • popover를 닫아도 항목은 미완료다. 다시 안내가 필요하면 LNB에서 같은 항목을 선택한다.
  • 성공 뒤 이 화면으로 자동 복귀하지 않는다. 실제 업무 화면의 정상 다음 CTA를 계속 사용한다.

접근성

  • LNB badge는 2/6처럼 텍스트로 읽히며 색만으로 진행을 표현하지 않는다.
  • 현재 단계 heading과 CTA로 focus 이동을 알리고, popover 닫기 뒤 focus를 원래 control 또는 페이지 heading으로 되돌린다.
  • mobile에서는 target을 가리지 않는 하단 card 형태를 사용할 수 있으나 같은 한 단계 안내를 유지한다.
  • motion 감소 설정에서는 spotlight transition을 줄이거나 제거한다.

CURRENT_LEGACY·IMPLEMENTATION_GAP

  • 기존 OnboardingWizard의 5단계 설정 flow와 OnboardingGate 강제 redirect는 CURRENT_LEGACY다.
  • 기존 LNB footer checklist, checklist_collapsed, hide_checklist, 72시간 자동 숨김은 목표 진행 계약이 아니다. 영구 숨김 write를 새 기능에서 사용하지 않는다.
  • 현재 StartGuideChecklist의 단순 Link 이동에는 목적 화면 focus·popover·1회성 intent 검증이 없다.
  • 실제 route·component·API가 목표 계약으로 교체되고 QA 근거가 생기기 전 구현 완료로 표시하지 않는다.

QA

  • LNB에서 열리고 Home 본문·우측 패널에 전체 체크리스트가 중복되지 않는다.
  • OWNER·ADMIN X/6, MEMBER X/4와 한국어 상태가 정확하다.
  • 일반 route 진입·새로고침·뒤로가기에서 안내가 자동 실행되지 않는다.
  • 명시적 CTA에서만 target focus·popover가 한 번 실행된다.
  • 화면 방문·popover 닫기로 완료되지 않는다.
  • 성공 뒤 업무 화면에 남고 LNB에서만 중단 지점을 재개한다.
