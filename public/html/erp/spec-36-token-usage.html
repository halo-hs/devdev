QA 기준

이 절은 앞선 제품 계약을 검증하기 위한 점검 항목이며, 독립적인 제품 요구사항을 추가하지 않는다.

  • Owner·Admin·Member가 현재 Space의 같은 집계 필드와 기준시각을 조회한다.
  • 다른 Space, 비활성 membership, 알 수 없는 역할은 데이터 flash 없이 거부된다.
  • Admin/Member 업그레이드 요청은 접수 상태만 만들고 외부 결제·구독을 바꾸지 않는다.
  • 업그레이드 요청은 Space+target당 하나만 활성화하고 24시간 중복을 합치며 30일 후 만료한다.
  • 사용량 조회 불가를 0·무료로 표시하지 않으며 역할 거부·상품 미구독·조회 실패를 구분한다.

개발 역추적

현재 서버의 Owner-only token usage gate와 프론트 Owner-only 직접 경로는 CODE_GAP이다. 목표 연결은 전 역할 current-Space 집계 사용량 조회와 역할별 Billing 행동이다. token usage page/components → lib/api/tokenUsage.ts, entitlements.ts → usage BFF → platform usage handler/service/data.
