CS-08 — ECOYA Platform Common Organization 멤버·초대

결정 반영: 2026-08-19 Organization·Paddle Customer·제품 관계 — COMMON:DEC-WORKSPACE-001

추가 반영: 2026-08-20 Common 설정 진입·Trade OS App User 경계

화면 목적

Organization Member 목록, 초대, OWNER/ADMIN/MEMBER 역할과 제품·메뉴 접근 권한을 설정 > 조직 > 사용자 관리 한 곳에서 관리한다.

용어

  • Organization Member: Organization Membership이 활성인 Account
  • Organization role: OWNER, ADMIN, MEMBER
  • 제품·메뉴 접근: Organization role과 별도 권한
  • App User: Organization 외부 제품 사용자. 이 화면의 멤버가 아님

권한

행동 OWNER ADMIN MEMBER
멤버 목록 허용 허용 불가
MEMBER 초대 허용 허용 불가
OWNER 지정·해제 허용 불가 불가
ADMIN 지정·해제 허용 불가 불가
MEMBER 변경·삭제 허용 허용 불가
MEMBER 제품·메뉴 접근 설정 허용 허용 불가
  • ADMIN은 OWNER·ADMIN을 변경·삭제하지 않는다.
  • 마지막 OWNER의 권한 해제·이탈은 거부한다.
  • OWNER 지정은 대상 Membership이 활성화된 뒤 수행한다.
  • ADMIN은 Organization의 active entitlement·Plan 범위를 넘는 접근을 부여할 수 없다.

초대

  1. OWNER 또는 ADMIN이 이메일로 Organization 초대를 만든다.
  2. ADMIN 초대의 역할은 MEMBER다. OWNER는 활성화 뒤 역할을 OWNER·ADMIN·MEMBER로 지정할 수 있다.
  3. 수신자가 Organization·초대자·대상 이메일을 확인한다.
  4. Account 인증과 이메일 일치 뒤 수락한다.
  5. 기존 Organization Membership을 만들고 새 Organization은 만들지 않는다.
  6. 제품·메뉴 접근을 별도 판정하고 /me·landing을 새로 조회한다.

제품·App User 경계

  • 제품별 Workspace Membership이나 제품별 멤버 관리 화면을 만들지 않는다.
  • 제품·메뉴 접근은 Organization Member 행의 별도 설정이다.
  • App User(USER, ANONYMOUS)는 목록·초대 역할에 포함하지 않는다.
  • Organization Member 초대와 Trade OS App User 초대는 서로 다른 기능이다. App User 초대·아이디 등록·제품 관리자 지정은 Organization Membership이나 Organization role을 만들지 않는다.
  • App User와 Account 연결은 `COMMON:DEC-IDENTITY-001`, 제품별 App User 운영은 제품 계약이 소유한다.

CURRENT_LEGACY

Trade OS legacy owner/admin/member와 SNAP legacy owner/admin/manager/worker/customer_viewer는 최종 Organization 역할·제품 접근·제품 사용자 분리에 맞춘 migration이 필요하다. SNAP /workers는 Organization Member와 제품 사용자·현장 참여자 기능을 분류하기 전 전체를 이 화면으로 이관하지 않는다. 기존 제품 역할 문자열을 자동 변환하거나 완료된 것으로 표시하지 않는다.

QA

  • OWNER 다중 지정, 마지막 OWNER 보호, OWNER/ADMIN 역할 제한을 확인한다.
  • ADMIN이 MEMBER만 초대·변경·삭제하는지 서버 부정 시험을 포함한다.
  • 제품 entitlement 밖 권한 부여가 거부되는지 확인한다.
  • 초대 수락이 새 Organization·제품 Workspace·구독을 만들지 않는지 확인한다.
  • App User가 Organization Member에 섞이지 않는지 확인한다.
  • Trade OS App User 초대·아이디 등록·제품 관리자 지정이 Organization 초대·역할 API를 사용하지 않는지 확인한다.
