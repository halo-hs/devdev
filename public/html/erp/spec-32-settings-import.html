SC-32 — 자료 가져오기 설정

Common 목표 경계: 2026-08-20 설정 진입·App User. 목표 표면은 Common 설정 허브의 Trade OS 구획이며, 이 문서는 제품 가져오기 필드·처리·오류와 기존 /erp/settings 구현을 소유한다.

결정 근거: TRADE-DOC-001 — QA 절의 규범 경계

항목 현행 값
주소 /erp/settings의 자료 가져오기 탭
화면 원본 settings page → CSV 가져오기 컴포넌트
담당 흐름 설정 (18-settings-members-billing.md), 영업 파이프라인 (20-sales-pipeline.md)
접근 가져오기 권한 사용자

파일·행동·호출

자료 종류 화면 항목 버튼·행동 호출 성공·오류·복구
연락처 CSV 선택 파일 가져오기 sales contacts import 생성·중복·오류 건수 표시
Deal CSV 선택 파일 가져오기 Deal import 경로 처리 결과 표시
형식 오류 파일명·오류 행 파일 재선택 호출 전 또는 응답 오류 성공 행과 실패 행을 분리

QA 기준

이 절은 앞선 제품 계약을 검증하기 위한 점검 항목이며, 독립적인 제품 요구사항을 추가하지 않는다.

자료 종류, 파일명, 열 이름, 전체·성공·중복·오류 건수와 화면 문구를 기록한다. 가져오기 결과를 목록 조회 결과와 혼합하지 않는다.

개발 역추적

import settings → salesContacts.ts:importSalesContacts와 Deal import client → BFF → import handler/service.
