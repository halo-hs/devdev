화면 구성

  • 1단계는 왼쪽 항목 검토·오른쪽 PDF 원문, 2단계는 왼쪽 PDF 원문·오른쪽 거래 연결의 전체 2분할로 표시한다. 두 패널의 너비는 사용자가 조절할 수 있다.
  • 2단계 오른쪽 패널은 연결 요약 → 거래 후보 → 직접 검색·새 거래 등록 순으로 배치하고, 하단 고정 액션바에서 항목 검토로 돌아가거나 연결을 확정한다.
  • 거래 연결 패널에는 PDF 다운로드를 두지 않는다.
  • 거래 연결 완료 후 별도 문서 확인·문서 확정 화면을 노출하지 않는다. 완료한 문서는 검토·배정 대기 목록에서 제외한다.

시작 가이드 T2·T3 variant

  • 일반 Confirm 진입에는 tour를 자동 실행하지 않는다. T2 또는 T3 체크리스트 CTA의 유효한 guide intent가 있을 때만 해당 단계 target을 focus하고 한 단계 안내를 연다.
  • T2는 anchor 문서의 AI 추출값·현재값·원문 근거·신뢰도를 구분해 실제 렌더한다. 사용자가 검토 CTA를 실행하고 서버 receipt가 저장된 때 완료한다. 문서 open·필드 렌더만으로 완료하지 않는다.
  • T3는 같은 문서를 사람 Confirm하고 정확하고 유일한 기존 거래를 선택하거나 새 거래를 만든 뒤 연결 commit이 성공해야 완료한다.
  • 거래 생성 성공 뒤 연결·commit 실패가 발생하면 생성한 거래와 선택을 보존하고 같은 operation부터 재시도한다. 중복 거래를 새로 만들지 않는다.
  • 성공 응답의 deal_id를 quickstart lineage에 연결하고 정상 제품 다음 행동을 계속한다. 시작 가이드로 자동 복귀하지 않는다.
  • 권한 회수·문서 접근 상실 시 문서명·거래 후보를 추가 노출하지 않고 T2/T3를 미완료로 유지한다.

QA 기준

이 절은 앞선 제품 계약을 검증하기 위한 점검 항목이며, 독립적인 제품 요구사항을 추가하지 않는다.

  • 문서 ID, 1·2단계, 필드 표시명, 현재값과 AI값, 누른 버튼, 오류 문구, 호출 결과를 기록한다.
  • 필드가 보인다는 사실만으로 생성 단계인지 수정 단계인지 추정하지 않고, 현재 화면 단계와 저장 행동으로 구분한다.
  • 사용자 수정값·AI 제안값·신뢰도를 하나의 값으로 기록하지 않는다.
  • 자동 연결은 OD-002의 정확하고 유일한 일치 조건을 사용하며 유사 일치나 일부 값만으로 연결하지 않는다.
  • 1단계 다음이 별도 화면 전환이 아니라 오른쪽 거래 연결 패널을 여는지, 패널을 닫으면 1단계의 기존 위치로 돌아오는지 확인한다.
  • 후보 행 선택만으로 연결되지 않고 선택한 거래 연결을 눌러야 배정·commit이 실행되는지 확인한다.
  • 후보 조회 실패 시 새 거래 등록이 노출되지 않고 다시 불러오기만 제공되는지 확인한다.
  • 거래 연결 완료 뒤 문서 확인·문서 확정 화면이 나타나지 않고 연결된 거래 상세로 이동하는지 확인한다.
