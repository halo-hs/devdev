이 화면은 공통 UI 품질 계약의 반응형 범위를 상속한다. 모바일에서도 카드별 상태·목록·빈 화면·오류와 다시 불러오기를 안전하게 표시하고, 목록·표의 가로 스크롤은 해당 컨테이너 안에서만 제공한다.

구역·행동·호출

구역 보이는 항목·버튼 주요 호출 성공·오류·이동
핵심 지표 위험 Deal, 연체 받을 돈, 선적 일정, 기준시각 업무 목록·정산·선적 요약 조회 카드 선택 시 Deal·정산·선적 조건 화면

인사이트·질문 자동/AI 요약, 시장 신호, 카드 열기/질문/숨기기 insight·NLQ·숨김 API 근거 답변 또는 모름; 관련 화면 이동
갱신 실패 실패 영역, 마지막 기준시각 다시 불러오기 실패 영역 재조회, 다른 성공 영역 유지

시작 가이드 T4 variant

  • 일반 /erp/home 진입은 현재 Home을 그대로 표시하고 질문 popover를 자동 실행하지 않는다.
  • T4 체크리스트 CTA의 유효한 guide intent가 있을 때만 질문 영역으로 scroll하고 입력 control에 focus한다.
  • 현재 quickstart의 deal_id를 사용자가 확인할 수 있는 거래 context로 표시하고, 해당 거래에서 답할 수 있는 추천 질문을 제공한다. 질문을 자동 제출하지 않는다.
  • 완료는 같은 deal_id 범위의 답변과 연결 문서 근거가 화면에 렌더되고 사용자가 확인한 때다. HTTP 200만으로 완료하지 않는다.
  • 근거 없음·다른 거래 근거·권한 거부·429·503·timeout은 T4 미완료이며 질문과 거래 context를 보존한다.
  • 성공 뒤 Home에 남고 시작 가이드로 자동 이동하지 않는다.

Home 본문에는 전체 시작 가이드 체크리스트·진행 panel을 두지 않는다. 진행 확인과 재개는 LNB 시작 가이드가 소유한다.

QA 기준

이 절은 앞선 제품 계약을 검증하기 위한 점검 항목이며, 독립적인 제품 요구사항을 추가하지 않는다.

카드명, 기준시각, 사용자 역할, 눌러 이동한 주소를 기록한다. 집계 조회 실패를 0건으로 표시하면 안 된다.
