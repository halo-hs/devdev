SC-34 — 이메일 수신 설정

Common 목표 경계: 2026-08-20 설정 진입·App User. 목표 표면은 Common 설정 허브의 Trade OS 구획이며, 이 문서는 제품 이메일 수신 필드·처리·오류와 기존 /erp/settings 구현을 소유한다.

결정 근거: TRADE-DOC-001 — QA 절의 규범 경계

항목 현행 값
주소 /erp/settings의 이메일 수신 탭
화면 원본 settings page → 이메일 수신 설정 컴포넌트
담당 흐름 문서 수신·검토 (01-document-intake-and-review.md), 설정 (18-settings-members-billing.md)
접근 조직 구성원; 주소 관리 권한은 서버 조건 적용

표시·행동

화면 상태 보이는 항목 버튼·행동 호출 성공·오류·복구
주소 표시 조직 전용 전달 주소, 사용 제한 안내 주소 복사 설정 조회 또는 기존 조직 응답 클립보드 결과 표시
주소 조회 실패 오류 안내 다시 조회가 제공되면 선택 같은 설정 조회 주소를 빈 문자열로 표시하지 않음

QA 기준

이 절은 앞선 제품 계약을 검증하기 위한 점검 항목이며, 독립적인 제품 요구사항을 추가하지 않는다.

실제 주소는 제보에서 마스킹하고 탭명, 복사 결과, 제한 안내, 오류 문구를 기록한다. 복사는 문서 수신 성공을 뜻하지 않는다.

개발 역추적

inbound email settings → 조직 profile·inbound configuration client → BFF → 조직 수신 설정 원본.
